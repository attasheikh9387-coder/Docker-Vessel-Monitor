# ShipTrack 🚢

A production-style containerized fleet telemetry platform.

## Overview

ShipTrack simulates a fleet of ships sending telemetry data such as:

- GPS position
- Speed
- Engine temperature
- Fuel level
- Engine status
- Timestamp

The platform processes this telemetry and presents fleet information through a web-based dashboard.

## Architecture

The final system will include:

- React frontend
- FastAPI backend
- PostgreSQL
- Redis
- Telemetry simulator
- Background worker
- Nginx reverse proxy
- Prometheus
- Grafana
- Docker
- Docker Compose
- GitHub Actions

## Project Goals

This project is designed to demonstrate practical knowledge of:

- Docker
- Docker Compose
- Container networking
- Persistent volumes
- Health checks
- Service discovery
- Environment configuration
- Container security
- Logging
- Monitoring
- Failure recovery
- CI/CD
